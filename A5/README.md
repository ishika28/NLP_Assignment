## DPO
DPO (Direct Preference Optimization) is a technique used in Natural Language Processing (NLP) to fine-tune models based on human preferences. 

1) Easier to Implement than RLHF (no need for a separate reward model or PPO).
2) Stable and Efficient fine-tuning for models like ChatGPT, LLaMA, etc.
3) Improves Model Alignment with human preferences in tasks like chatbot responses, summarization, and content moderation.
